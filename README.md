# PKチャレンジ リッチ版

## 公開URL
https://hisasue-kimomil.github.io/pk-challenge-rich/

## 紹介と使い方
5つの方向（左上・右上・左下・右下・真ん中）からボタンを選んでPKを蹴ります。5本中3本決めたら勝利です。
1本ごとに「10000通りのうち何番目のシュートか」が出ます（方向5 × 乱数 10 × 20 × 10）。

## 工夫した点
- 結果の4種類（外れ・止められた・届かずゴール・逆をついたゴール）ごとに、キーパーの絵・ボールの動き・効果音・観客が変わる
- 上の5本のマークで、何本目か、どんな結果だったかがひと目で分かる
- 決着したら名言が出て、自動でスタート画面に戻る
- あえてドット絵にしてアナログゲーム感を出した
