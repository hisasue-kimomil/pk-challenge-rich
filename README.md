# ①課題名
PKチャレンジ リッチ版

## ②課題内容（どんな作品か）
- 5つの方向（左上・右上・左下・右下・真ん中）からボタンを選んでPKを蹴るアプリ。5本中3本決めたら勝利
- 1本ごとに「10000通りのうち何番目のシュートか」を表示（方向5 × 乱数 10 × 20 × 10）
- 課題1のPKチャレンジを、ドット絵・結果ごとの動き・漫画風の効果音・名言でリッチにした

## ③アプリのデプロイURL
https://hisasue-kimomil.github.io/pk-challenge-rich/

## ④アプリのログイン用IDまたはPassword（ある場合）
- なし

## ⑤工夫した点・こだわった点
- 結果の4種類（外れ・止められた・届かずゴール・逆をついたゴール）ごとに、キーパーの絵・ボールの動き・効果音・観客を変えた
- 上の5本のマークで、何本目か、どんな結果だったかがひと目で分かるようにした
- 決着したら名言が出て、自動でスタート画面に戻るようにした
- あえてドット絵にしてアナログゲーム感を出してゲームのシンプルさとトーンを合わせた

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 量が多いのと、少し変えるだけで複数替わるので大変
- 同じ処理を5方向に写して書いたので、量が多すぎるので、こういったものを簡素化できるようにしたい
